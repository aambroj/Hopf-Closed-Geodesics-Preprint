## Research claim / Afirmación investigada

For smooth functions h on [-1,1] satisfying 0 < h(u) <= 1/2, the manuscript proposes an exact shortest closed-geodesic length of 2π for a specified family of Hopf metrics on S³. The proof is presented for scrutiny and has **not** received independent mathematical validation. Originality has not been established.

El manuscrito propone que una familia de métricas de Hopf sobre S³, parametrizada por funciones suaves h con 0 < h(u) <= 1/2, tiene longitud mínima de geodésica cerrada exactamente 2π. **No ha sido objeto de una verificación matemática independiente** ni se ha establecido su originalidad.
